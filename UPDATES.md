# Выпуски YASNO

Текущий веб-выпуск: 2026.11.08.3 (номер сайта, не Android versionCode).

Исправлено отображение обновлений: открытая веб-версия отделена от доступной на сервере, список изменений подписан номером открытой версии. «YASNO обновлён» не показывается одновременно с предложением применить подготовленное обновление. Доступный номер появляется после успешной проверки; сам по себе он не означает, что загрузка уже завершена.

В этом выпуске упрощено письмо «Сообщить о проблеме»: понятные вопросы с двоеточиями и свободными строками, необязательные сведения о телефоне и версии Google Play. Версия сайта подставляется автоматически; версия Android-приложения недоступна сайту и не выдумывается. Кнопка только открывает черновик в почтовом приложении, отправляет его пользователь.

Для публикации загрузить вместе index.html, feedback.js, sw.js, release.json и UPDATES.md. UPDATES.md — инструкция, приложение её не читает.

При каждом выпуске изменённых файлов:
1. Изменить APP_VERSION и тексты «Что нового» (последняя строка каждого языка APP_UPDATE_LABELS) в index.html.
2. Указать тот же номер в release.json.
3. Повысить CACHE в sw.js.
4. Опубликовать связанные файлы вместе. release.json должен быть доступен рядом с index.html; его запросы не кэшируются service worker.

Проверка выполняется при запуске, возвращении в приложение (не чаще раза в минуту), восстановлении сети и каждые 15 минут в видимом окне. Ошибки не блокируют погоду. Время проверки относится к текущей сессии.

Подготовленный service worker активируется после закрытия всех окон под старой версией. «Применить сейчас» активирует его и перезагружает только запросившее окно. Другие окна не перезагружаются. Пока приложение открыто, автоматической перезагрузки нет. HTML запрашивается сначала из сети, с запасной копией при сбое. Сведения о выпуске показываются один раз; новые установки только запоминают текущую версию.

После публикации проверьте на телефоне: кнопку, закрытие и повторное открытие раздела, проверку без сети, применение следующего выпуска и однократное сообщение после перезапуска.

## Android / Google Play

Проверка касается только сайта. Исходников Android-оболочки и надёжного способа получить установленный Android versionCode в проекте нет. Поэтому плашка Google Play не показывается: иначе она может появиться у уже обновившихся пользователей. Для неё нужна доработка Android-проекта PWABuilder с проверкой доступного конкретному пользователю обновления через Google Play In-App Updates и новая AAB-сборка. Прогноз не блокируется.
